# Voi Customer Portfolio Engine

Interactive customer portfolio equity model for our Customer Centricity term paper (Voi Technology, Oslo).
Open `index.html` in any browser, or visit the GitHub Pages address for this repository.

- Every exhibit in Appendix A has a scenario code; `#s=central`, `#s=city`, `#s=late`, `#s=pess` and `#s=opt` reopen the named scenarios.
- **A4 appendix** in the top bar renders the printable appendix; print it and choose Save as PDF.
- All calculations run locally in the browser. No data is collected or sent anywhere.

Student analysis, not affiliated with or endorsed by Voi Technology.
