# Five minute first-time-reader test

Status: PREPARED, NOT RUN. Recruit three readers who did not help build the simulator. Test individually, with no coaching, using the default Simple view or the paper's case link.

## Task and timing

Start a five-minute timer when the page opens. Ask the reader to answer:
1. Which design should be prioritised, and which implementation path is proposed?
2. Why that design, using at least one value-versus-cash comparison?
3. What observation or changed assumption would make you change the choice?

The facilitator may repeat the task but may not explain labels, point to controls or suggest an answer. Stop at five minutes and record unanswered items. Then ask which label or action was confusing.

## Record each reader separately

Reader ID; previous simulator familiarity; device; start/end time; design/path answer; reason and numbers used; decision-changing condition; navigation steps; mistaken interpretations; requests for help; task completion within five minutes.

## Acceptance and next step

All three should identify the conditional Hub & Book pilot-first priority, distinguish it from the highest-total-value combination, and identify a relevant operating or funding condition that could overturn it within five minutes. Answers in the reader's own words count; recalling exact numbers does not. Record failures before revising the interface and retest with new readers. Do not report a pass until these sessions have actually occurred.
